# Titanic Dataset Exploratory Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on the Titanic dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset inspection
- Missing value analysis
- Statistical summary
- Age distribution visualization
- Survival analysis
- Correlation analysis

## Findings
- Missing values exist in Age and Cabin columns.
- Most passengers were between 20 and 40 years old.
- Survival depended on several factors including class and fare.
